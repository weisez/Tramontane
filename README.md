# Tramontane Central Station

Официальный сайт центральной станции Трамонтана, полицейский департамент Сан-Фиерро (2nd Area Command).

**Сайт:** <https://weisez.github.io/Tramontane/>

## Что внутри

| Раздел | Содержание |
|---|---|
| Главная | Девиз, вступление, подразделения, последние брифинги и пресс-релизы |
| О станции | История, здание и помещения, зоны ответственности и структура SFPD |
| Подразделения | Патруль, секция бандподавления, спецназ, программа полевой подготовки, управление станции |
| Состав | Схема управления, личный состав, вакансии |
| Карьера | Путь в полицию, карьерная лестница, кадровый смотр |
| Документы | Приказы, брифинги, служебные записки в виде официальных бланков (печать, ссылка) |
| Пресс-центр | Пресс-релизы станции |
| Формуляры | Заявления, рапорты и обращения: форма заполняется на странице, текст копируется |
| Доска станции | Неформальная жизнь станции |

Поиск по сайту: `Ctrl+K` или `/`. Тёмная и светлая темы.

## Структура репозитория

```
Tramontane/
├── index.html      # каркас страницы
├── css/style.css   # оформление
├── js/             # скрипты по функциям (подключаются по порядку)
├── data.json       # весь контент сайта
├── img/            # картинки (загружаются через «Медиа»)
├── og.png          # превью для ссылок в мессенджерах
└── favicon.svg
```

Сайт статический, сборки нет. Весь контент хранится в `data.json`.

## Публикация на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)`.

## Редактирование

Редактировать может только владелец: нужно один раз открыть сайт по секретной ссылке (она хранится у владельца, в репозитории её нет). После этого в шапке появляется панель владельца:

1. **Режим правки** показывает кнопки ✎ у каждого элемента: люди, подразделения, документы, формуляры, события, помещения и т. д. Тексты документов редактируются в редакторе с форматированием, картинками и ссылками.
2. **Медиа** загружает картинки в `img/` репозитория и выбирает их из библиотеки.
3. **Опубликовать** показывает список изменений и коммитит `data.json` одним действием. Точка у кнопки означает неопубликованные правки. «История» позволяет вернуться к прошлой версии.
4. **Данные** экспортирует и импортирует JSON (резервная копия).

Для «Медиа» и «Опубликовать» нужен токен GitHub (Fine-grained, только этот репозиторий, право *Contents: Read and write*): «Медиа» → ⚙. Токен хранится только в браузере.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000/>. Сервер нужен, чтобы страница могла загрузить `data.json`.
