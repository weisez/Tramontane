## События без пересборки сайта

События лежат в `events.json` (а не в `data.json`) и читаются прямо с GitHub, поэтому новое или изменённое событие видно всем через несколько секунд, без «Опубликовать» и без ожидания GitHub Pages.

- Владелец: режим правки → «+ Событие» / ✎ на карточке → «Сохранить». Каждое действие — отдельный коммит `events.json`. Нужен токен GitHub («Медиа» → «Подключить»), тот же, что для объявлений.
- Посетители подтягивают обновления сами раз в минуту, пока открыта главная, афиша или страница события.
- Событие с галочкой «Черновик» видит только владелец. Прошедшие события уходят в архив автоматически.
- Если `events.json` недоступен, показывается последняя сохранённая в браузере версия.
